# Security policy

## Supported versions

Security fixes are applied to the latest release on the `main` branch.

## Reporting a vulnerability

Do not publish suspected vulnerabilities in public issues. Contact the maintainer privately with a description, affected version, reproduction steps, and any proof of concept. Allow a reasonable time for acknowledgement and remediation before public disclosure.

## Privacy boundary

Ghost processes camera frames locally. The application has no network feature. Screenshots are written only after an explicit user action and should be handled as sensitive visual data by the operator.
